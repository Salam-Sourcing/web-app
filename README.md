# web-app

Salam Sourcing's official web application starter, built with **Astro + React + shadcn/ui-style components**.

## Tech stack

- Astro
- React
- Tailwind CSS (for shadcn-compatible styling)
- class-variance-authority + clsx + tailwind-merge

## Pages included

- `/` Landing page
- `/login`
- `/marketplace`
- `/about`

## Project structure

```txt
src/
  components/
    marketing/
    shared/
    ui/
  layouts/
  lib/
  pages/
  styles/
```

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```
